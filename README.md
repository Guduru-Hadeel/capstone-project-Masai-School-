#Zepto Data & AI Platform
📌 Overview
This repository contains the capstone project for Zepto’s analytics guild. It demonstrates an end‑to‑end AI/ML workflow across three modules:

/data_pipeline — Scraping, cleaning, currency conversion, and relational database storage.

/analytics — Titanic dataset profiling, EDA, predictive modeling, and regression analysis.

/support_assistant — A GenAI support assistant built with embeddings, LangGraph orchestration, and FastAPI, running in offline mock mode.

All three modules live together in this single repository. Deliverables are textual (.py, .ipynb, .md). Chart images generated by notebooks may be included as supporting artifacts but are never substitutes for written interpretation.

▶️ Run Instructions
**Module 1 — Data Pipeline (/data_pipeline)**
Run the notebook/script to scrape data from books.toscrape.com.

Clean and convert fields, apply fixed currency conversion (1 GBP = 105.50 INR).

Load data into a normalized SQLite database.

Execute ≥ 5 SQL queries demonstrating SELECT, WHERE, ORDER BY, LIMIT, DISTINCT, JOIN.

Verify equivalence between SQL join and pandas merge.
 
 **Module 2 — Analytics (/analytics)**
Run the EDA notebook to profile and clean the Titanic dataset.

Save titanic.csv as the offline fallback.

Perform univariate, bivariate, and multivariate analysis with written interpretations.

Train Logistic Regression, Decision Tree, and Random Forest classifiers.

Evaluate with confusion matrix, accuracy, precision, recall, F1, ROC/AUC.

Compare imbalance handling strategies (baseline, balanced weights, SMOTE).

Tune Random Forest hyperparameters and report OOB score.

Complete regression side‑task predicting fare.

Save the best pipeline with preprocessing + estimator using joblib.

**Module 3 — Support Assistant (/support_assistant)**
Ensure the 8 policy documents are present in /docs.

Embed documents locally with sentence-transformers and store in ChromaDB.

Build LangGraph with nodes for intent classification, retrieval, and answering.

Run FastAPI app locally with uvicorn.

Test queries to confirm structured JSON responses (answer, source_docs, confidence).

📝 Design Decisions

**Data Pipeline**
Scraped ≥ 60 books across ≥ 3 categories.

Cleaned fields with imputation/dropping invalid rows.

Applied fixed currency conversion.

Normalized schema with PK/FK relationship.

**Analytics**
Applied threshold rules for missing values.

Outliers detected via IQR rule.

Survival analysis broken down by sex, pclass, and combined.

Compared classifiers with full metric suite.

Regression task added for fare.

Best pipeline saved for reproducibility.

**Support Assistant**
Offline mock LLM implemented (graded baseline).

Embeddings generated with sentence-transformers.

ChromaDB used for local vector storage.

LangGraph orchestrates intent classification, retrieval, and response.

FastAPI provides structured JSON output.
